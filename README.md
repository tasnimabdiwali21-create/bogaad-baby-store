# Bogaad Baby Store

Website responsive ah oo af-Soomaali ku qoran, loogu talagalay Bogaad Baby Store.

## Faylasha
- `index.html`: website-ka oo dhan (HTML, CSS iyo JavaScript).

## Sida loo daawado
1. Fur repository-ga GitHub.
2. Gal `index.html`.
3. Si aad online ugu daabacdo, fur **Settings → Pages**, dooro **Deploy from a branch**, branch-ka `main` iyo folder-ka `/ (root)), kadibna Save.

## Ka hor inta aan la daabicin
Ku beddel qaybta xiriirka cinwaanka, lambarka telefoonka/WhatsApp iyo bogagga bulshada ee rasmiga ah. Hubi qaybaha alaabta iyo helitaankooda. Foomka xiriirku fariinta ayuu diyaariyaa; si toos ah uma dirayo fariin ilaa adeeg diris lagu xiro.
