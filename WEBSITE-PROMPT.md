# Prompt: Bogaad Baby Store Website

Create a complete, polished, responsive e-commerce showcase website for “Bogaad Baby Store”, a Somali baby and children’s store. Use HTML, CSS, and vanilla JavaScript, and publish the project to the existing public GitHub repository tasnimabdiwali21-create/bogaad-baby-store (main branch). Do not create another repository.

## Brand identity
- Main brand name: “Bogaad”; smaller subtitle: “Baby Store”.
- Cute, modern, elegant, premium and warm — not overly childish.
- Pastel pink, baby blue, cream, white, and subtle lavender.
- Rounded cards, soft shadows, friendly typography, delicate stars/clouds/teddy/baby-bottle motifs.
- Mobile-first, accessible, responsive design.
- All customer-facing text must be natural Somali.

## Website sections
1. Sticky responsive navigation: Bogga Hore, Qaybaha, Alaabta, Nagu Saabsan, Nala Soo Xiriir.
2. Hero headline: “Daryeelka iyo farxadda ilmahaaga, hal meel” with CTA buttons “Eeg Alaabta” and “Nala Soo Xiriir”.
3. Categories: Fiitamiinnada Carruurta, Multivitamins, Daryeelka Ilmaha, Dharka Ilmaha, Kabaha & Agabka, Alaabta Carruurta.
4. Product cards focused especially on children’s vitamins and multivitamins, with product images/placeholders, Somali descriptions, and prices clearly marked as placeholders until confirmed.
5. A clear note that vitamins should be used according to a healthcare professional’s guidance and are not a substitute for a balanced diet. Avoid unsupported medical promises.
6. About section describing the family-focused mission without inventing a physical address, phone number, certifications, or customer reviews.
7. Trust/value section about helping parents explore products for their children.
8. Contact/order form with name, phone, product/message, validation, and a contact button. Use clearly editable placeholders for phone/WhatsApp details; do not invent a real number.
9. Footer with navigation and editable social-media placeholders.

## Functionality and quality
- Working category filtering, product search, responsive mobile menu, and client-side form validation.
- The form should clearly explain whether it only prepares a message; do not pretend it sends an order or processes payment if no real service is connected.
- Semantic HTML, keyboard focus states, useful alt text, SEO title/description, and reduced-motion support.
- Create `index.html` with embedded CSS and JavaScript so it can run on GitHub Pages without a build step.
- Create `README.md` with setup steps, instructions to edit placeholder contact/product details, and instructions for enabling GitHub Pages using `main` and `/(root)`.
- Commit the files to the existing public repository `tasnimabdiwali21-create/bogaad-baby-store`.
- After committing, verify the repository files and provide the repository URL. Do not claim the live website is published until GitHub Pages confirms deployment.
